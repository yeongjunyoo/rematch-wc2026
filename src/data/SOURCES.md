# 데이터 출처 대장 (source register)

시나리오 선언에 들어간 모든 사실의 출처를 기록한다. 축구 팬이 오류를 즉시 간파하므로 확인되지 않은 값을 넣지 않고, 불명확한 값은 자체 재구성으로 표식한다.

작성 2026-07-26. 데이터 동결 예정 D4(2026-07-30).

## 출처 등급

| 등급 | 의미 |
|---|---|
| `confirmed` | 공개 기록과 보도에서 시각과 득점자까지 교차 확인된 사실 |
| `reconstructed` | 흐름은 확인되었으나 세부 값을 게임 목적으로 직접 재구성 |
| `authored` | 사실이 아니라 게임 설계상 저술한 값(능력치, 미션 커트라인, 시드 덱) |

능력치 6축과 미션 커트라인과 시드 덱은 전부 `authored`다. 실제 선수의 능력을 평가한 값이 아니며 게임 균형을 위한 설계 수치다.

## 저작권과 톤 규칙

- 경기 결과와 일정과 선수명은 사실 정보이며 저작권 보호 대상이 아니다.
- FIFA와 각 연맹과 구단의 엠블럼, 선수 사진, 중계 영상, 공식 폰트는 사용하지 않는다.
- 국기와 유니폼은 자체 제작 인라인 SVG 도형으로만 표현한다. `crestKey`는 그래픽 키 문자열이며 외부 자산을 참조하지 않는다.
- 실존 인물과 팀에 대한 비하 표현을 넣지 않는다. 홍명보 감독과 손흥민을 포함해 모든 서술은 헌정과 존중의 톤을 유지한다.
- 대통령 발언 등 정치적 논평은 인용하지 않는다.

## 시뮬레이션 계수 provenance

능력치 6축, 포메이션 상성, 팀 지시 가중은 모두 `authored` 게임 균형 설계값이다. 실존 선수의 능력 평가가 아니며, 특정 선수와 닮도록 작성하지 않는다.

Hattrick 리버스엔지니어링 논문은 계수의 prior와 감도 밴드 출처로만 사용한다. 이 프로젝트는 그 수치를 재현했다고 주장하지 않으며 경험적으로 검증되었다고도 주장하지 않는다.
