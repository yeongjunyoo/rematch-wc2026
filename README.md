# REMATCH

손흥민이 벤치에 있던 그 밤을, 당신이 다시 지휘한다.

실제 월드컵 명승부의 결정적 순간에서 경기를 이어받아, 전술 개입으로 결과를 다시 쓰는 미션형 시뮬레이터입니다. DAKER 월간 해커톤 「내가 축구 감독이라면, 월드컵 전술 웹서비스 챌린지」 출품작입니다.

## 실행 방법

사전 요건은 Node.js 22 이상입니다. 개발에는 Node 24.18.0을 사용했습니다.

```bash
npm install
npm run dev        # 개발 서버
npm run test       # 단위 테스트와 종료 경로 fixture
npm run typecheck  # 타입 검사
npm run build      # 정적 번들 산출 (dist/)
npm run preview    # 산출된 번들 로컬 확인
npm run smoke      # 빌드된 번들의 전체 라우트 렌더 검사
npm run e2e        # 실제 브라우저에서 경기 루프 종단 검사
npm run verify     # 위 전부를 순서대로 실행하는 배포 전 관문
```

## 사용 기술

| 영역 | 선택 |
|---|---|
| 프레임워크 | React 19, Vite, TypeScript (strict) |
| 시뮬레이션 엔진 | 순수 함수, 시드 기반 결정론 |
| 테스트 | Vitest |
| 라우팅 | URL 해시 기반 자체 구현 (정적 배포에서 직접 진입 안전) |

외부 API를 호출하지 않습니다. 모든 데이터는 저장소에 포함된 정적 선언입니다. 심사자가 회원가입이나 결제나 API 키 없이 확인할 수 있습니다.

## 현재 구현 상태

**동작하는 것**: 다섯 시나리오, 이어받는 시점부터 분 단위로 흐르는 경기 시계와 재생 제어(일시정지, 1배속과 2배속과 4배속, 끝까지 건너뛰기), 더그아웃 드래그 편집(자유 배치와 슬롯 교환과 벤치 교체 카드), 팀 지시 다섯 축, 개입 토큰 세 개와 변화 없는 확정 거절, 관측 지연과 예산과 쿨다운을 가진 상대 AI 반격, 경기 형식 상태기(정규시간, 연장, 골든골, 승부차기, 종료), 관점 상대적 종료 사실과 선언적 진출 판정, 등급 판정과 역사 대비 리포트, 매치 코드와 시드 덱 기반 새 리매치, 브라우저에만 저장되는 명예의 전당, 해시 라우팅과 없는 주소 안내 화면.

**아직 없는 것**: 실제 선발과 벤치 명단의 출처 교차검증 완료, 공유 이미지 카드, 역사 시점 표식과 분기 프롬프트, 사건별 전용 연출.

## 주요 파일

```
src/domain/types.ts        도메인 계약. 경기 형식 상태기, 종료 사실, 시드, 전술 지시
src/domain/engine.ts       국면 전이 상태기, 승부차기 진행, 종료 사실 파생
src/domain/simulate.ts     재개 가능한 경기 런타임. 배치와 재생이 공유하는 유일한 전이 함수
src/domain/outcome.ts      진출 판정 truth table, 등급 판정, 역사 대비
src/domain/rng.ts          worldSeed와 decision draw 분리, 매치 코드, 개입 차분
src/domain/records.ts      명예의 전당. 브라우저 저장소만 사용
src/screens/MatchRoom.tsx  경기 재생과 개입 루프
src/screens/Dugout.tsx     Pointer Events 기반 전술 편집 오버레이
src/data/scenarios/        시나리오 선언 5종
tests/fixtures/            단위 테스트와 다섯 종료 경로 fixture
scripts/smoke.mjs          라우트 렌더 검사
scripts/e2e.mjs            브라우저 종단 검사
```

## 설계에서 중요한 결정 두 가지

**경기 종료를 데이터로 선언한다.** 정규시간 종료, 연장(2026년의 완주 연장과 2002년의 골든골), 승부차기, 조별 진출 판정이 모두 `MatchFormat` 선언과 상태기로 표현됩니다. 그래서 서로 다른 종료 방식을 가진 시나리오가 코드 분기가 아니라 데이터 추가로 성립합니다. 다섯 시나리오가 `regulation`과 `extraTime`과 `goldenGoal`과 `shootout` 네 가지 결정 국면을 모두 덮는 것을 fixture가 증명합니다.

**인과가 보이는 결정론을 목표로 합니다.** 시도 단위로 고정된 `worldSeed`가 분과 팀 같은 외생 추출을 지배하고, 사용자 행동에 의존하는 추출은 따로 분리했습니다. 이렇게 하면 슬라이더를 한 칸 움직여도 미래의 난수 흐름이 통째로 바뀌지 않아, 전술 변경이 결과를 바꾼 것인지 운이 바뀐 것인지 사용자가 구분할 수 있습니다. 같은 매치 코드는 같은 경기를 재현하고 새 리매치는 공개된 시드 덱을 인덱스로 전진합니다. 매치 코드에는 엔진 버전과 데이터 버전이 함께 들어가고, 버전이 다른 코드는 현재 엔진으로 조용히 재생되는 대신 거부됩니다.

**화면의 경기와 리포트의 경기는 같은 한 개의 전이 함수를 씁니다.** 재생은 그 함수를 한 걸음씩 부르고 배치 실행은 끝까지 부릅니다. 두 경로가 같은 결과를 낸다는 것은 다섯 시나리오와 개입 유무 모두에서 테스트가 단언합니다.

## 화면 아트

모든 그림은 코드 안의 인라인 SVG와 CSS로 직접 만들었습니다. 이미지 파일이 하나도 없습니다.

**생성형 AI 이미지는 쓰지 않았습니다.** 대회 요강이 허용하고 있어 검토했지만, 접근 가능한 생성 서비스의 약관이 용도를 개인 학습과 연구와 체험으로 제한하고 산출물의 지식재산권 귀속을 보증하지 않아 채택하지 않았습니다. 자세한 근거는 `src/data/SOURCES.md`에 적었습니다.

엠블럼과 선수 사진과 중계 화면과 공식 서체는 쓰지 않았고, 실제 국기도 그대로 재현하지 않았습니다. 팀 상징은 색과 추상 도형의 조합입니다.

## 데이터 출처와 라이선스

경기 결과와 일정과 선수명 같은 사실 정보만 사용했고 공개 보도와 공개 기록을 참고해 직접 재구성했습니다. 사실 정보 자체는 저작권 보호 대상이 아닙니다.

FIFA와 각 연맹과 구단의 엠블럼, 선수 사진, 중계 영상, 공식 폰트는 일절 사용하지 않았습니다. 국기와 유니폼 표현은 자체 제작한 인라인 SVG 도형입니다.

모든 시나리오는 실존 인물과 팀에 대한 헌정과 존중의 톤으로 작성했습니다. 특정 선수나 팀이나 국가를 비하하는 표현은 포함하지 않습니다.
